Why I built it

Most Linux courses rely on simulated terminals. They teach the syntax of a command, but not how a real system responds to it.

The problem

Simulators accept a fixed list of commands and return canned output. Trainees memorize answers instead of exploring. Installing Linux on shared lab computers is not practical, and most trainees cannot run it at home.

The approach

Every trainee gets a real Ubuntu system, isolated in its own container and opened with a single click. It works the same from a lab computer or a laptop at home. Nothing to install, and nothing a mistake can break for anyone else.

What it does

One platform covers the whole practical workflow, from the first lesson to the final grade sheet.

For trainees

Learn by doing

  • A personal Ubuntu container in the browser, with files that persist between sessions.
  • Recorded lessons that replay the instructor's terminal so trainees can follow along at their own pace.
  • Exercises checked automatically against the actual state of the system, not against a typed answer.
  • Personal progress indicators for lesson adherence and command accuracy, compared with an anonymous class average.
  • A “My mistakes” page that collects failed commands for review.
For instructors

See every terminal, live

  • Live monitoring of all trainee terminals during class, with the option to step in and help.
  • One-click lesson recording: the instructor's terminal is streamed and saved as a replayable lesson.
  • An exercise editor that verifies each model solution in a disposable container before publishing.
  • A 16-week course calendar aligned with the official plan, with reminders before exams.
  • Role-based access for the platform admin, instructors, and read-only reviewers.
  • Arabic and English interfaces, switchable per user, so any institution can run its own course.
Exams

Practical exams, graded fairly

  • Timed exams with a countdown, questions as a file or as written items, and a dedicated exam mode.
  • Automatic grading that matches what the trainee actually ran against an answer key, accepting renamed files and self-corrected mistakes.
  • Manual questions and paper marks combined into one total.
  • PDF grade sheets and a CSV export ready for upload to the official learning management system.
  • Cross-section statistics: highest and lowest scores, scores below 50%, absences, and barred trainees.
Privacy & security

Built with care for trainee data

  • Minimal personal data, a published privacy policy, and trainee consent on first sign-in.
  • Hardened containers: rootless Docker, a read-only base system, dropped capabilities, and per-trainee disk quotas.
  • Salted scrypt password hashing, login throttling, and one-time recovery codes.
  • An audit log of every administrative action.
  • A full security review in November 2026, with fixes deployed in prioritized batches.

A deliberately simple stack that one person can build, run, and maintain on a single virtual server.

Resilience

About the project

I am Sami Al-Mutairi, a computer and information technology trainer. I designed, built, and operate Linux Lab on my own, and I use it to teach the practical side of my operating systems course.

The course content follows the LPI Linux Essentials objectives, spread over a 16-week plan with two lectures a week. Every feature on this page came from a real classroom need, and most were shaped by feedback from the trainees who use it.
